# Лабораторна робота 3: Потоки телеметрії IoT

Проєкт обробляє дані з IoT-датчиків за допомогою Java Stream API.
Дані надходять як нескінченний потік, тому кожен метод сам зупиняється і ніколи не зависає.

Тип даних — `SensorMetric`: id пристрою, тип метрики, значення і час.

Клас `TelemetryStreamAnalyzer` має три методи:

- `findFirstAnomaly` знаходить першу метрику від заданого пристрою зі значенням,
  більшим за критичну межу. Повертає `Optional`, який порожній, якщо нічого не знайдено.
- `streamActiveMetrics` пропускає перші метрики, поки їхнє значення не більше
  за нормальну межу (`dropWhile`), а потім бере не більше `maxCount` метрик (`limit`).
- `calculateMovingAverages` бере лише метрики одного типу і рахує ковзне середнє
  для кожного нового значення. Використовує власний `Gatherer`, який зберігає
  останні `windowSize` значень. Поки значень менше за `windowSize`, рахує середнє
  з усіх, що вже є. Кількість результатів обмежена параметром `outputLimit`.

Якщо аргумент дорівнює `null` або числовий аргумент менший або рівний 0,
методи кидають `IllegalArgumentException`.

Весь код цієї лабораторної знаходиться в пакеті `ua.kpi.comsys.streams`.

## Варіант

- Номер залікової книжки: N = 22
- Варіант: V = N mod 3 = 22 mod 3 = **1**
- Завдання: варіант 1, телеметрія IoT-пристроїв у реальному часі

## Налаштування проєкту

- Система збірки: Gradle (Kotlin DSL, `build.gradle.kts`)
- Версії бібліотек задані в каталозі версій: `gradle/libs.versions.toml`
- Бібліотека для тестів: JUnit 5
- Java 25 (потрібна для `Gatherer`)

Gradle wrapper вже є в проєкті, тому окремо встановлювати Gradle не потрібно.

## Тести

Тести використовують нескінченні потоки, створені через `Stream.iterate` і `Stream.generate`.
Тести з нескінченними потоками мають `@Timeout(2)`, тому вони впадуть, якщо метод не зупиниться за 2 секунди.

## Як запустити тести

На macOS або Linux:

```bash
./gradlew test
```

На Windows:

```bash
gradlew.bat test
```

Зібрати проєкт і запустити всі тести:

```bash
./gradlew build
```

Звіт про тести: `build/reports/tests/test/index.html`.
