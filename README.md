# Лабораторна робота 2: Менеджер історії дій

Проєкт на Java, який збирається і тестується за допомогою Gradle.

Клас `ActionHistoryManager` зберігає історію дій користувача.
Він працює як функція «скасувати» в текстовому редакторі:

- `performAction` додає нову дію на вершину історії.
- Історія має максимальний розмір. Коли вона заповнена, найстаріша дія видаляється.
- `undo` видаляє і повертає найновішу дію.
- `peekRecentAction` повертає найновішу дію, але не видаляє її.
- `getHistory` повертає копію всіх дій, від найновішої до найстарішої.
- `getHistorySize` повертає кількість дій.
- `clear` видаляє всі дії.

Всередині клас використовує `java.util.Deque` зі стандартної бібліотеки Java.

Весь код цієї лабораторної знаходиться в пакеті `ua.kpi.comsys.collections`.

## Варіант

- Номер залікової книжки: N = 22
- Варіант: V = N mod 3 = 22 mod 3 = **1**
- Завдання: варіант 1, менеджер історії дій з обмеженням ємності

## Налаштування проєкту

- Система збірки: Gradle (Kotlin DSL, `build.gradle.kts`)
- Версії бібліотек задані в каталозі версій: `gradle/libs.versions.toml`
- Бібліотека для тестів: JUnit 5
- Java 25

Gradle wrapper вже є в проєкті, тому окремо встановлювати Gradle не потрібно.

## Як запустити тести

На macOS або Linux:

```bash
./gradlew test
```

На Windows:

```bash
gradlew.bat test
```

Зібрати проєкт і запустити всі тести:

```bash
./gradlew build
```

Звіт про тести: `build/reports/tests/test/index.html`.
