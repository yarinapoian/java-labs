# Лабораторна робота 1: Транзакції

Проєкт — проста система грошових транзакцій на Java.

Кожна транзакція — це об'єкт даних, який не можна змінити після створення.
Є три види транзакцій: `Deposit` (поповнення), `Withdrawal` (зняття) та `Transfer` (переказ).
Клас `TransactionProcessor` приймає транзакцію і повертає текстовий звіт про неї.

Весь код знаходиться в пакеті `ua.kpi.comsys.dop`.

## Варіант

- Номер залікової книжки: N = 22
- Варіант: V = N mod 3 = 22 mod 3 = **1**
- Завдання: варіант 1, фінансова система транзакцій

## Вимоги

- Java 25
- Gradle wrapper вже є в проєкті, тому окремо встановлювати Gradle не потрібно

## Як запустити тести

На macOS або Linux:

```bash
./gradlew test
```

На Windows:

```bash
gradlew.bat test
```

Зібрати проєкт і запустити всі тести:

```bash
./gradlew build
```

Звіт про тести: `build/reports/tests/test/index.html`.
